# Jana Veljanovska

A personal website about economics, people, and culture.

Built with semantic HTML, CSS, and a small amount of JavaScript. No build step or runtime dependencies. Fonts and photographs are served locally.

## Preview

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`.

## Edit

- `index.html` — biography, interests, IB MYP education, initiatives, awards, and activities.
- `styles.css` — layout, colors, typography, responsive styles, and animation.
- `script.js` — scroll illustrations, reveals, reading progress, and motion controls.
- `assets/images/` — optimized copies of the original photos in `photos/`.
- `assets/fonts/` — self-hosted DM Sans and Instrument Serif, with their OFL licenses.

The TEDx initiative is described as an application in progress. Update that wording when its status changes. The public contact address is `jv4299@nova.edu.mk`. Résumé highlights are included in the page; the source résumé contains private contact details and is not linked or needed for deployment.

## Publish

GitHub Pages serves the root of the `main` branch at `https://janaveljanovska.github.io/`. Enable **Deploy from a branch → main → / (root)** under the repository’s **Settings → Pages** if necessary.

The site supports mobile layouts, keyboard navigation, reduced motion, and a persistent pause-motion setting. Content also remains readable with JavaScript disabled.
